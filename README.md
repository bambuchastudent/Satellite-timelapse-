# Satellite Timelapse

Хронологическая галерея спутниковых снимков и аэрофотосъёмки для любой точки Земли.

**Место по умолчанию:** стадион у координат `33.67740833, -7.27224444` (Марокко).

[Открыть сайт](https://bambuchastudent.github.io/Satellite-timelapse-/) — доступен после включения GitHub Pages и успешного развёртывания.

## Возможности

- Просмотр кадров по датам в одном окне, автопрокрутка и лента миниатюр.
- Ввод новой широты и долготы: десятичные координаты (`33.67740833, -7.27224444`) или DMS (`33°40'38.67"N 7°16'20.08"W`).
- Кнопка **Стадион** возвращает исходную точку.
- Прямая ссылка на выбранное место: `?lat=33.67740833&lon=-7.27224444`.
- Источники: Esri World Imagery Wayback, OpenAerialMap и Sentinel-2 STAC. Фильтры дат/облачности, выгрузка CSV.

Все снимки запрашиваются непосредственно из сторонних сервисов при открытии страницы. Часть сервисов может быть недоступна из-за ограничений CORS, прекращения работы API или отсутствия покрытия. Версии Wayback обозначают даты публикации, если дата исходной съёмки неизвестна; Sentinel-2 часто показывает обзор всей сцены, а не увеличенную заданную точку. USGS/ANCFCC доступны по ссылкам без автоматического импорта.

## GitHub Pages

Сайт представляет собой один `index.html` без этапа сборки. Workflow `.github/workflows/pages.yml` публикует сайт из ветки `develop`.

Если Pages ещё не включён, владелец репозитория должен выбрать **Settings → Pages → Build and deployment → Source: GitHub Actions**. Затем запустить workflow **Publish Satellite Timelapse to GitHub Pages** (Actions → Run workflow), если он не стартовал автоматически.
