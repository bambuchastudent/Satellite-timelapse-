📱 Настройка «CF Сбор»

Для Chrome на Android: запуск собирает публичные названия, цены, ссылки и EAN, когда он указан на странице Carrefour.

1. Скопируй код закладки

Важное: код устанавливается только как адрес закладки, не в строку поиска.

2. Создай закладку в Chrome

  1. Добавь эту страницу в закладки (⋮ → звёздочка).
  2. Открой редактирование закладки.
  3. Назови её CF Сбор.
  4. В поле «URL/Адрес» вставь скопированный код, который начинается с javascript:.
  5. Сохрани закладку.

3. Собирай товары Carrefour

  1. Открой каталог акции.
  2. Нажми адресную строку Chrome, введи CF Сбор, выбери именно подсказку-закладку (не поиск Google).
  3. Откроется вкладка импорта Satellite. Данные уже окажутся в локальном кэше.
  4. Вернись к Carrefour: скрипт может ловить динамические обновления открытой страницы. После полноценной перезагрузки/перехода повтори запуск закладки.

Для передачи на другие устройства открой вкладку импорта и подключи ограниченный GitHub PAT с доступом Contents: Read and write только к Satellite. Секрет не нужно передавать ChatGPT.

Что не собираем

Cookies, адреса, учётную запись Carrefour, карту лояльности, корзину покупок и персональные данные. EAN сохраняется только если он явно опубликован на странице; похожие названия не считаем доказательством участия в акции.
