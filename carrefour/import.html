    Общий кэш GitHub

    Синхронизация изменяет только carrefour/community.json в репозитории Satellite. Используется GitHub REST API, без собственного сервера. Токен остаётся только в текущей вкладке Chrome (sessionStorage).

    Без токена товары остаются в локальном кэше. Не пересылай ключ в чат и не вводи токен с доступом к другим репозиториям.
