# Satellite · редактор квартиры v2

Статический бесплатный 2D/3D-редактор. Исходники — HTML/CSS/JavaScript (ES modules), Three.js, glTFLoader и glTFExporter. Нет аккаунтов, серверной базы или платного рендеринга. На GitHub Pages работает без сборки: `/apartment-editor/`.

## Что изменилось

- Непрямоугольная квартира из отдельных контуров комнат. Начальный эскиз содержит гостиную, спальню, кухню, две дополнительные комнаты справа, прихожую с ломаной стеной и балкон. **Все исходные размеры приблизительные** — это не точная оцифровка красных линий на скриншоте.
- Общие вершины смежных комнат: перетаскивание красного угла в плане двигает все связанные стены. Можно выбирать и передвигать стены целиком, менять длину, толщину, добавлять угол посередине выбранной стены.
- Выбор помещения и кнопки «шире/уже, глубже/мельче» с шагом 10 см. Можно добавить прямоугольную комнату справа или нарисовать произвольный контур несколькими касаниями и замкнуть.
- Окна и двери размещаются на **любой** выбранной стене; метки можно двигать вдоль стены. Синие — окна, жёлтые — двери. Цвет комнаты и фотографии покрытия пола можно менять.
- Режимы «План», «Как в Sims» (изометрия), обычная 3D-перспектива, фасады спереди/сзади/слева/справа.
- Мебель можно добавлять и двигать на плане, менять размер и угол. Есть импорт GLB-моделей мебели, экспорт полной сцены в GLB для Blender и локальный JSON для дальнейшей работы.
- На телефонах снижено разрешение рендеринга, нет непрерывного цикла кадров, перетаскивание перестраивает геометрию не чаще одного раза за ~75 мс. Реальную скорость на конкретном телефоне нужно проверять вручную.

## Управление

1. Открой страницу, выбери «План». Красные точки — углы, зелёные — середины стен, голубые — окна, жёлтые — двери. Перетаскивай пальцем или мышью.
2. Нажми стену для редактирования толщины и длины, добавления окна/двери или ещё одного угла.
3. Нажми пол комнаты, чтобы изменить название, цвет, условные размеры или добавить фото пола.
4. Для свободного многоугольника выбери «+ Контур комнаты», нажми минимум три точки и «Замкнуть контур».
5. Нажми «◈ Как в Sims» или «◈ 3D», чтобы рассмотреть квартиру под углом, либо выбери фасад из меню. Для точного перетаскивания углов вернись в «План».
6. «Сохранить JSON» — перенос между устройствами. «Экспорт GLB» — импорт в Blender: File → Import → glTF 2.0.

## Совместимость и ограничения

- При первом открытии v2 читает старый `localStorage`-ключ `satellite-apartment-editor-v1` и переносит мебель и свободные перегородки в расширенную модель. Старое сохранение не удаляется. Старые JSON версии 1 можно открыть вручную.
- Автосохранение работает только в данном браузере/устройстве. Для резервного копирования всегда сохраняй JSON; не полагайся на localStorage как единственное место хранения.
- Дверные и оконные проёмы прорезают стену на уровне визуализации, но пока не моделируют дверные полотна/петли, оконные рамы по ГОСТ или сложную арочную геометрию.
- Перемещения углов могут изменить форму соседних комнат; пересечения рёбер внутри одного помещения блокируются. Однако пересечения между разными независимыми помещениями пока не проверяются.
- «Как в Sims» означает изометрическую ортографическую камеру и срез стен, а не полноценные инструменты The Sims.
- Изображения пола и большие импортированные GLB-модели могут увеличить размер JSON и замедлить устройство. Модели мебели лучше импортировать до 8 МБ.
- HTML может обращаться к CDN за кодом Three.js при загрузке; данные квартиры никуда автоматически не отправляются.

## Разработка

```sh
cd apartment-editor
node --test tests/*.test.mjs
python3 -m http.server 8000
```

Открыть `http://localhost:8000` (запустить сервер в каталоге `apartment-editor`, иначе открыть `/apartment-editor/`). Сервер не нужен при использовании GitHub Pages.

Движок и геометрия: `geometry.js` — независимая от браузера модель; `editor.js` — Three.js, взаимодействия и файловый обмен; `editor.css` — стили. Старая версия оставлена в `app.js`, `model.js`, `style.css` для истории.
