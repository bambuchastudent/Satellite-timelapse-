# План квартиры — Satellite

Открыть редактор: https://bambuchastudent.github.io/Satellite-timelapse-/apartment-editor/

Это минимальный бесплатный редактор вида сверху.

## Возможности

- План гостиной, спальни, кухни, коридора, балкона.
- Изменение размеров комнат в метрах.
- Дорисовывание прямых перегородок нажатием двух точек.
- Добавление, перетаскивание и изменение размеров условной мебели.
- Сохранение/загрузка редактируемого JSON.
- Экспорт картинки PNG и модели GLB для Blender.

## Blender

Скачай GLB из редактора, открой Blender → File → Import → glTF 2.0.
Модель содержит простые объёмные стены, пол и условную мебель.
После импортирования можешь сохранить как файл Blender.

## Ограничения

Это черновик, не точный обмер квартиры. Окна и двери на плане условны.
Дорисованные перегородки — прямые сегменты, без дверных проёмов.
Удаление перегородок работает в обратном порядке.
GLB не содержит точной геометрии окон и дверей. После изменения ширин комнат проверь мебель и перегородки.

## Технологии

Статический HTML без сборщика, платных API и сервера данных.
Konva.js (MIT) для 2D и Three.js (MIT) для GLB-экспорта, подключены с jsDelivr.
Нужен интернет для загрузки библиотек. Все личные правки сохраняются в localStorage браузера.
Чтобы сохранить и перенести работу, скачай JSON.
Не публикуй личный чертёж в открытом репозитории, если не хочешь сделать его общедоступным.
